# Portafolio Personal — Nicolás Botero Mora

## Descripción

Sitio web de portafolio personal desarrollado como proyecto del Sprint 4 del curso de desarrollo web de TripleTen. Presenta información profesional, habilidades técnicas, proyectos destacados y datos de contacto en un diseño responsivo con tema oscuro.

## Funcionalidad

- Sección de perfil con foto, bio y enlaces a CV, GitHub y LinkedIn
- Sección de habilidades y herramientas con iconos
- Sección de proyectos destacados con imagen, descripción y enlaces a demo y repositorio
- Sección de contacto con correo y redes sociales
- Efectos visuales con degradados radiales en el fondo
- Diseño completamente responsivo para escritorio, tablet y móvil

## Tecnologías y técnicas utilizadas

- HTML5 semántico
- CSS3: Flexbox, Grid, Custom Properties, Media Queries
- Fuentes: Archivo Black y Open Sans (Google Fonts)
- Degradados con `linear-gradient` y `radial-gradient`
- Diseño responsivo con breakpoints en 1023px y 767px
- Posicionamiento absoluto para efectos de superposición en tarjetas
